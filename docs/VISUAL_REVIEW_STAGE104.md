# Stage104：卡宾枪机匣截面与接合件

沿用 stage31 的第一人称优先方向，本轮重建卡宾枪：上机匣横向缩至原截面的 78%（最宽站位约 60 mm），下机匣宽度由 67 mm 改为 54 mm；同步移动抛壳口、内部枪机、侧面凹槽、销钉、保险及上肩加强条。金属粗糙度略降，使肩部与侧壁的反光变化更明确。导轨与瞄具高度、护木及手臂动画保持原有基准。修改 `tools/build_assets.py`，重新生成 `art/carbine.blend`、`client/assets/carbine.glb`。

本轮手臂资产没有重建；目标是先减少持枪画面中占比很大的机匣块状感。手套虎口接触、逐指包握与袖子褶皱仍需专门改善，不能将收窄枪体等同于手臂完成。

实际审阅：已逐张查看源码卡宾枪腰射、ADS、换弹 50% 全分辨率图，并查看 `stage103-104-carbine-comparison.jpg`。同机位对照中上机匣侧壁与肩部收窄可见，但整体轮廓变化有限，枪托、拉机柄和下部大平面仍显得粗壮，不能声称积木感已消除。ADS 红点保持画面中心、视窗无遮挡；当前三张姿态未见调整后的销钉与侧件明显悬空。换弹图仍清楚暴露虎口空隙及手指没有自然环握的问题，是下一阶段必须解决的重点。

另已查看包内卡宾枪腰射、ADS 全分辨率截图：新机匣正常显示，红点居中，视窗未被手臂遮住；仍可见粗壮拉机柄、平板侧壁及缺少结构变化的袖子。源码与包内三枪五姿态总览均已直接审阅，其他两枪本轮没有重建。

验证输出在 `artifacts/realism104-validation/`，本地预览在 `artifacts/realism104-preview/Linux/`。固定位置、朝向的腰射/ADS 对照保留游戏本身的 ADS 视野变化；源码与包内版本均采集三枪腰射、ADS、换弹 25%/50%/75%。最终数量与通过情况以 `test-results.json`、`verification.json` 为准。
