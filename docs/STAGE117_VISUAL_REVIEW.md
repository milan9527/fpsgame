# Stage117 环境设施、山脚与光照

本阶段继续环境优先级。在仓库东侧加入带抱箍、弧形顶盖、管路和基础的供水罐，在入口院落加入连续排水格栅。山体横向山脚变宽，林木沿同一高度函数贴地；环境光从 0.35 降至 0.30，日光从 1.15 降至 1.08，方向不变。没有把整个画质目标判为完成。

## 实机审阅

- 正常步行入口机位可辨认排水沟，仓库通道仍清楚。水罐从仓库东侧步行机位观察；最初机位被仓库转角遮挡，随后对基线和新包使用同一个无遮挡机位重拍。
- 最终水罐截图可辨认圆柱轮廓、抱箍和管路，但罐身缺少接缝、污渍等表面细节，标字的曲面贴合感不足，仍有程序几何感，不能视为写实设施验收完成。
- 山脚更连贯，但宽幅画面的平坦空旷前景、重复仓库体量、孤立尖峰仍明显。植被数量和贴地检查不能代替画面质量验收。
- 整体受光稍暗，维修棚内顶面仍过亮；降低全局光强未解决该局部受光问题。下一阶段需要检查棚顶材质和遮光，而不是继续整体压暗场景。
- 本轮没有验收第三人称人物和第一人称连续换弹动作。入口截图包含手臂与武器，但静帧不能作为动作、瞄准或联网验收的替代。

## 证据与复现

`artifacts/realism117-validation/before` 的七张环境截图和维修棚截图来自 stage116 已验证包；水罐机位使用 stage116 包重新拍摄。`after` 使用最终 stage117 包；相机 JSON 记录位置、目标、朝向、眼高和分辨率。`camera-comparison.json` 与并排对照图用于复核相同机位，未改变曝光来制造差异。

功能检查结果见 `functional-results.json` 和各测试日志；包括瞄准、武器遮挡、单机、入口/屋顶碰撞、仓库/雨棚/维修院落通行及供水罐阻挡与绕行。水罐新增独立弧顶凸包碰撞，并从上方射线验证命中。

首次水罐绕行测试走出目标设施区域，碰到既有场景障碍而失败；原始失败日志保留在 `initial`。最终将路线限定为水罐侧方 z=28 至 z=39 的双向通行，不删除阻挡断言；罐体侧面和顶盖另做碰撞断言。

最终包的一次功能批次以 143 退出，原因未确认，未收齐退出码；日志保留在 `interrupted`。随后改为逐项落盘结果并重新运行，最终状态以 `functional-results.json` 为准。

`background-scenery.log` 检查 18 个山体、1159 棵树和 253 棵幼树，最大树根高度误差 0.000093 米。该检查运行于补充水罐顶盖碰撞前的 stage117 包；地形和植被代码此后未变。

截图使用 Forward+ / llvmpipe。真实联网缺少可用认证 fixture，未读取密钥；本地网络状态规则通过不代表真实多人联网通过。运行方式见 `artifacts/realism117-preview/README.md`，构建及验证汇总见对应 `build.json` 和 `verification.json`。

下一步继续消除棚顶异常受光、仓库重复及地面空旷，并审阅供水设施的表面细节；随后继续第三人称护具/蹲姿、第一人称连续动作及具备合法测试条件后的真实联网。当前整体目标状态为 continue。
