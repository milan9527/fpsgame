# 武器外观与挂点

AR-30、SG-8 和 SR-5 分别使用原创 `carbine.glb`、`shotgun.glb`、`marksman.glb`，在 `art/` 保留对应 `.blend` 源文件。`tools/build_assets.py` 调用 `build_weapon_variants.py` 生成完整资产；所有模型以同一机匣和握把坐标为基准，Blender +Y 前方转换为 Godot -Z 前方。

每种枪含合并静态枪身、独立弹匣和两块枪托，共四个网格对象。第一人称隐藏枪托，保留弹匣换弹动作。霰弹枪设定为使用可拆卸弹匣的 SG-8；现有动作没有宣称实现管式逐发装弹。狙击枪有独立长枪管、开放镜筒和折叠脚架外观；枪栓尚无专属操作动画。

`SightAnchor` 和 `MuzzleAnchor` 由 Blender 导出。第一人称读取挂点进行瞄具居中和枪口特效定位；缩放视野分别为 48°、58°、24°。狙击瞄准目前使用全屏 FOV 缩放与真实镜筒孔洞，不是独立镜片渲染或真实光学模拟。

第三人称角色蒙皮不再包含固定步枪。Godot 根据快照中的武器编号实例化对应枪模，使用 `Weapon` 骨骼的当前姿态相对静止姿态的变换进行挂接；走、蹲、换弹、死亡和瞄准会随骨骼运动。只有本地玩家实例化第一人称枪模和手臂，远端角色仅分配第三人称枪模。视觉切换不执行弹药转移或伤害逻辑。

当前三把枪仍共用手臂动作和基本握持。手指贴合、武器专属换弹/拉栓动作、贴墙收枪、反射镜片、纹理与材质精修仍待完善。

验证入口：`tests/weapon_visuals_rules.gd` 检查三个模型、网络状态驱动切换、骨骼挂接、每把枪的瞄具与枪口、视野、网格数量和弹药守恒。`--capture-weapons` 生成六张实际 OpenGL 截图。两客户端测试通过可靠切枪请求依次切到 SG-8、SR-5，并检查远端模型已与快照编号一致。
