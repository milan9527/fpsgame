## 定量定位与本轮功能证据

`checks/sleeve-reach.json` 来自新增 `tests/sleeve_reach_review.gd`：
三种武器、左右手、每种 101 个状态共 606 个记录。左肘夹角约
31.57–142.07 度，最大肩部漂移小于 0.000001 米；右肘约 110.96 度。
采样没有支持“肩部漂移或肘部完全拉直”的猜测。下一步应优先修改袖形、
腕部衔接和取景，而非盲目调整 IK。此测量是直接设置换弹进度的诊断，
不覆盖 ADS、移动或连续输入。

## 三武器第一、第三人称动作复验

`motion-lod-cull/process-result.json` 最终退出 0：三武器分别完成第一人称、
第三人称站姿和蹲姿，共九段、261 个样本。每段覆盖换弹起止，验证末帧弹量恢复；
九张接触表均已逐张查看，`motion-lod-cull/viewer.html` 可逐帧复核。
第一人称相机位置 `(0, 1.6003644466, 90)`、旋转 `(0, 0, 0)`；
第三人称相机位置 `(2.7999999523, 1.50010252, 65)`、
旋转 `(-0.133232832, 2.390663624, 0)`。逐帧元数据保存实际位置和朝向。

- 三武器均观察到左手离开护木、取匣、下移、装回与回握；右手保持握把。
  长直袖管、袖口鼓起和手套硬转折持续出现，肩部位于第一人称画面外。
- 第三人称站姿和蹲姿的躯干、头部及肩带几乎不随换弹调整，动作僵硬。
  面部细节不足、护膝和肢体分面明显；蹲姿中弹匣与手常被胸前装备和膝部遮挡，
  不能据这些远景样本确认无穿插或接触自然。
- 采集每六个模拟帧取样，约 10Hz；不是实时连续视频。
  未覆盖其他武器 ADS、移动中换弹、站蹲切换、打断切枪和联网动作。

补齐诊断裁剪后第一人称图元约 515 万降至 123 万，单张采集约 105 秒降至
7.7 秒；这是诊断场景工作量变化，不是正式游戏帧率结论。
