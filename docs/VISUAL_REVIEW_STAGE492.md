# Stage492：道路外缘地形与当前预览复验

## 本轮变更

`client/scripts/world_visuals.gd::road_graded_shoulders` 将道路外缘从较窄浅坡改成宽度延伸到 12m 的不等高土坡，加入沿路沉积起伏和横向冲刷低口；建筑及服务场地出入口连续压低。负高度外边界在入口压低时保留负值，避免把埋入草地的边缘抬成直边。显示网格和 trimesh 碰撞使用同一几何。

这是地形剖面修改，仍受整张平坦草地底面限制，不能形成低于零面的真实排水沟。未修改人物、手臂、建筑或光照资产。源文件修改前副本与差异在 `artifacts/realism492-validation/source-before/` 和 `road-structure.patch`。
