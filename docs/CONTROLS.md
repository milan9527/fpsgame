# 键盘控制设置

主菜单和暂停菜单都提供 KEYBOARD CONTROLS。点击动作对应按键，再按一个键完成修改；等待输入时 Escape 取消本次捕获，再按 Escape 返回。列表可滚动，包含战斗和观战动作。Escape 固定为菜单退出，鼠标左键射击、右键瞄准和滚轮观战缩放保持固定。

修改采用单个物理键，不支持组合键、鼠标重映射或手柄。物理键代表键盘位置，标签按引擎键名显示。支持常用字母、数字、标点、方向键、修饰键和 F1–F24。冲突不会自动交换或覆盖其他动作：战斗动作之间、观战动作之间分别检查重复；观战和战斗允许复用按键，因为两种状态不会同时操纵角色。

配置保存到 `user://bindings.cfg`，先写临时文件再替换目标文件，保存失败时保持旧输入配置并显示错误。加载时校验完整配置的类型、键值与冲突，坏文件回退到默认。与音量、鼠标灵敏度的 settings.cfg 分开保存。RESTORE DEFAULT KEYS 恢复并保存默认键位。

菜单、HUD 补给/治疗/投掷提示、武器栏、地图、背包、观战切换与名单提示读取实际绑定。离线暂停菜单内改键时游戏保持暂停；在线暂停菜单内世界继续运行，但玩家操作保持中立。捕获按键不会触发重装、开火或关闭其他菜单；关闭面板清除仍按住的动作，避免误触。

测试使用隔离配置文件验证改键重载、战斗冲突、观战复用、Escape 保留、坏配置回退、保存失败及恢复默认；图形事件测试验证按键捕获、取消、暂停保留和游戏输入隔离。不会修改玩家的真实 bindings.cfg。

`tools/test_bindings_network.py` 使用真实客户端的物理按键事件验证改键后的权威移动和预测纠正，并验证在线面板内世界继续推进而角色保持中立输入。
