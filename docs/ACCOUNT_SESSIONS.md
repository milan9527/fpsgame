# 账户会话与退出所有设备

登录后，主菜单账户区的 `SIGN OUT ALL` 会使该账户现有登录全部失效。游戏内先返回主菜单再操作。成功后清空本机令牌和密码输入；重新登录会获得有效的新会话。

`POST /auth/logout-all` 使用 Bearer JWT，按令牌携带的版本条件更新 PostgreSQL `users.session_version`。并发退出只有一次成功。受保护 HTTP 请求读取并锁定账户版本，旧 JWT 返回 401；旧版无 `ver` 的 JWT 仅在账户版本为 0 时兼容。

入场票据携带相同版本，消费时再次核对数据库，退出前领取但尚未使用的票据不能继续入场。Redis 清理只释放旧预约；数据库提交后的失效状态不会因缓存错误而撤销。清理失败返回 503，客户端提示未确认；401 仅表示当前凭据失效，不宣称已退出其他设备。

专用服务器每次心跳上报在线账户版本，API 返回已失效账户。服务器立即停止接收该玩家的新操作，发送退出通知并断开 ENet。正常心跳间隔约 2 秒；API 或数据库不可用时不能保证及时断开。此功能没有设备列表、单设备撤销或密码找回。

验证：`backend/tests/test_sessions.py` 使用独立测试数据库及 Redis 前缀检查版本、并发、票据和缓存故障；`tools/test_session_logout.py` 启动两个真实 Godot 客户端，一个在线对局，另一个登录同一账户并退出全部设备，检查在线断开、旧令牌拒绝及重新登录。
