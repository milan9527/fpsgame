# Stage99：拇指连续曲面、瞄具肩线与动画导出修复

本轮状态 **continue**。本轮解决一个完整构建流程的动画污染问题，并改善局部第一人称轮廓；整体画质目标仍未完成。

## 实施与构建

- 拇指中心线改为端点保持的 Hermite 插值，截面改为更接近椭圆、减弱关节收腰，使转折连续。保留现有骨骼和握持位置。
- 同步收窄反射瞄具外壳、内缘和密封圈上部肩线，增加顶部弧度，保留瞄准中心。
- 完整资产构建会先生成第三人称角色，再在同一个 Blender 进程生成第一人称手臂。首次验证发现旧角色动画残留，第一人称 GLB 导出了19个动作，导致 viewmodel_rules 的四动作断言失败。生成手臂前清除旧动作后重新完整构建、导入、导出并复验。早期失败记录保存在 before-fix-test-results.json 和 before-fix-viewmodel_rules.log。
- 最终保存的 carbine 和 first_person Blender 网格校验无无效网格；直接解析 GLB 确认只有 Heal、Hold、Reload、Throw 四个动作，见 final-mesh-topology.log。构建中右手减面出现重复三角形，导出前已有清理流程完成修复。

## 实际截图审阅

位置固定为 (17, 0.05, 50)，朝向 atan2(-18, 16)，俯仰 -0.03；冻结世界物理，腰射与 ADS 保持各自正常视场角。stage98-99-viewmodel-comparison.png 使用相同机位、相同像素尺寸的裁切。

腰射中瞄具上部从方框变为略收窄的圆肩轮廓；拇指的折角减轻。ADS 原图能看到拇指过渡更圆，但仍像细长弯管，掌面、虎口与护木接触关系不自然。机匣依然厚重，袖管仍缺少自然褶皱与袖口层次。此次形体变化不能称为完整的手部重塑或显著写实提升。

卡宾枪换弹中段原图未见腕部断开；握把周围手指仍显僵硬，弹匣握持缺乏可信的指腹接触。接触规则测试只能说明约束通过，不能证明视觉上完全没有穿插。

另行打开预览包的卡宾枪腰射与 ADS 原图，瞄具轮廓和手部形体与源码运行一致，红点位于画面中心；上述细长拇指与厚重机匣问题在包内同样存在。

重复仓库、斑驳墙面、规则成簇植被与裸地仍明显。人物、建筑差异、地形植被和光照没有在本轮得到实质改进。下一轮应直接重构掌指与枪械接触的整体比例和虎口，而非继续孤立微调拇指参数；同时推进场景差异和真实多人验证。

## 验证与运行

最终记录见 artifacts/realism99-validation/test-results.json 和 verification.json。源码及包内分别执行武器材质、手套表面、瞄准、换弹接触、武器遮挡、第一人称绑定、武器显示、单机冒烟、入口碰撞、屋顶碰撞和联网状态规则测试。实际截图覆盖三把武器各五种姿态，源码与包内各15张。

最终驱动退出0，22项功能检查、1次导出与2次截图采集共25条成功记录。已打开源码及包内两张姿态总览：三把武器均有腰射、ADS和三个换弹时点，未见模型整件丢失；两组可见姿态一致。缩略图不足以排除细小穿插，手指接触仍需按原图改进。

网络状态规则不是实际多人联机验证。截图使用 Forward+ / llvmpipe 软件 Vulkan，不能代表硬件 GPU 性能。导入退出0仍报告 dummy texture storage 的 Parameter "t" is null，尚未修复。
