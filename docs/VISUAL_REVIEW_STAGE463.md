## 修改和可复核结论

`client/shaders/road_surface.gdshader` 将道路纹理过滤改为三线性 mipmap，保留随机旋转的显式梯度采样；法线扰动改为解析噪声梯度，避免对屏幕导数继续求导。新增独立道路绘制脚本和有超时、输入哈希、真实退出状态的运行器，环境运行器支持标记为诊断用途的 GL 渲染。

在本机 Godot 4.4.1 / Mesa llvmpipe 软件渲染器上，462 完整道路着色器、禁用凹凸和仅改解析法线的隔离绘制都超时。平面材质成功；改用三线性过滤的道路隔离绘制成功，5.325 秒退出0并生成 PNG。这支持各向异性过滤与显式梯度采样组合在此驱动上的问题判断，不能推广为所有 GPU 的性能结论。诊断证据在 `artifacts/realism463-validation/isolated-*`；失败日志均保留。

当前包 Forward+ 实机道路图成功，单机位运行258.614秒。这证明当前渲染路径能够生成实机帧，**不能证明交互帧率合格**。
