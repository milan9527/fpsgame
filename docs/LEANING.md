# 左右探身

按住 Z/C 左右探身，同时按住两键回正。与 E 拾取及 Q/E 观战切换不冲突。最大倾角 18°，约 0.2 秒达到完整幅度；站立眼位最大横移约 0.38 米，蹲姿幅度随眼高降低。冲刺或离地时回正，探身移动速度最多 2.8 米/秒。菜单、背包与地图屏蔽探身输入。

角色模型和碰撞胶囊绕下端球心一起倾斜，眼位由同一变换计算。物理采样每次最多改变 0.025 探身量，使用略缩小 1 厘米的胶囊检测场景和角色阻挡，避免地板接触被误认为阻挡。贴墙时保留最后可用幅度，空间不足时回正也可能暂时受阻。站起净空检查考虑当前倾角。

探身属于持续移动输入，由服务器验证范围和有限数值；客户端预测同样的姿态变化，并通过服务器探身快照纠正和重放输入。远端角色使用快照姿态。枪口阻挡检测也考虑视点偏移与枪械滚转。即时射击使用真实倾斜碰撞体；延迟补偿保存姿态基点和旋转，将射线转换到胶囊局部空间，避免已露出的头部只有视觉效果却无法命中。

当前采用整个角色模型的程序化倾斜，尚无独立上半身探身动画、脚部 IK 或机器人掩体探身战术。极小碰撞余量与身体动画之间仍可能存在视觉差异。

`lean_rules.gd` 覆盖视点/真实碰撞、爆头、倾斜回溯、薄墙、冲刺/离地、蹲姿、快照、恶意输入和菜单隔离。双客户端在线回归要求双方观察到自身与另一玩家的探身。
