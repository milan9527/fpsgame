## 实际修改

`tools/build_viewmodel.py` 将袖管原有两道圆滑隆起改为六组非对称布料折面，覆盖朝向相机的前臂下侧。宽松布面在末端收进窄褶，左右臂错开折向，重新生成 `art/first_person.blend` 与 `client/assets/first_person.glb`。保留此前布料、手套与补强材质；本轮没有重做枪械或环境，也没有改变握持骨骼和瞄准参数。

- 卡宾枪 stage68/69 对照：腰射下前臂现在能读到斜向折面；ADS 下袖管仍在下方，红点位置保持居中。改善范围有限，手臂仍显厚，布褶偏软且部分收褶边缘不够自然。
- 霰弹枪换弹中段：袖口至前臂收褶更明显，手套织纹可见；枪托仍是大块均匀黑色，枪械与手的接触自然度仍需进一步提高。
