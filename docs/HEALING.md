# 医疗包与主动取消

生命不足且有医疗包时按治疗键（默认 H）开始 3.5 秒治疗。治疗过程中移动速度为 2m/s；完成后恢复最多 65 点生命并消耗一个医疗包。

治疗尚未完成时，再次按治疗键或在背包点击 `CANCEL MEDKIT` 可以取消。取消不回血、不消耗医疗包，解除治疗带来的移动减速及动作限制。HUD 会显示当前绑定的取消键。重新治疗从完整时长开始；完成的治疗不能撤回。

协议 15 使用独立的 `cancel_heal` 动作意图，通过现有可靠、有序且带回合编号的动作通道发送。取消指令与开始治疗不可同时为真，不从不可靠移动消息执行。迟到的取消在治疗已经完成时只清除计时，不会误开第二个医疗包；序号去重也防止旧取消影响后来开始的治疗。

机器人在有效手雷逃生路线生效时，调用同一个取消方法并暂不重新治疗，从而解除治疗减速。这不改变普通烟雾治疗或实体掩体治疗规则。

取消发生在服务器确认后，联机客户端继续使用权威计时同步；不保证高延迟时按键瞬间就解除减速。库存和治疗计时沿用原存档结构。

验证：`tests/heal_cancel_rules.gd` 检查库存、速度恢复、键盘/背包、重复和迟到指令；`tools/test_heal_cancel_network.py` 使用真实专服客户端验证开始、取消、完整治疗，以及旧取消不能打断新治疗。
