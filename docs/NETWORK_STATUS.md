# 联机网络状态

在线对局的小地图下方显示连接状态；单机隐藏。数据来自现有 ENet 连接和当前回合角色快照，不增加探测 RPC。

- `RTT`：ENet 统计的往返延迟，单位毫秒，每 250 毫秒采样。
- `VAR`：ENet 的 RTT 波动统计，单位毫秒；不是丢包率。
- `LAST UPDATE`：距最近一个有效角色快照分包的时间。它不代表所有角色都收到同一帧更新，也不等于输入确认时间。
- 首次同步期间显示 `SYNCING WITH SERVER`，一秒观察期后显示已取得的 RTT。尚未收到角色快照时显示等待时间。
- RTT 达到 180ms 提示 `HIGH LATENCY`，波动达到 60ms 提示 `UNSTABLE NETWORK`。
- 一秒没有当前回合角色快照时优先显示红色 `SERVER UPDATES DELAYED`，收到更新后自动恢复。旧回合消息不会刷新计时。

这是一项玩家提示，不改变射击、预测或服务器超时策略，不提供自动重连。API、数据库等后端健康状态也不由此指标推断。新回合重新测量，返回菜单清除。

`tests/network_status_rules.gd` 验证状态边界、无效指标、旧回合隔离和生命周期；`tools/test_network_status.py` 通过真实 UDP 代理加入单向 75ms 延迟，并在战斗中阻断下行数据 1.8 秒，检查 Godot HUD 告警、恢复和连接保留。
