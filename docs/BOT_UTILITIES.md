# 机器人投掷物战术

机器人使用与玩家相同的投掷、库存、刚体、引信和烟雾遮挡规则，不会凭空生成烟雾或直接恢复生命。

巡逻寻补给时，缺少烟雾且仍有医疗包的机器人会考虑烟雾物资。生命低于 55、有医疗包、记得最近看见的敌人、没有可用实体掩体且无需进圈时，会向附近地面投掷一枚烟雾弹。随后蹲下停止射击和移动，最多等待 8 秒；实际烟雾遮断自己与已知威胁位置的视线后才开始普通 3.5 秒治疗。生命恢复至 65 以上或等待超时后结束驻留，进圈会立即打断驻留。

决策间隔按机器人编号错开至约 0.8–1.12 秒。烟雾成功投掷后有 18 秒战术冷却，破片手雷有 12 秒冷却；两类共享此冷却，仍受换弹、治疗、投掷动作和世界投掷物数量上限约束。破片手雷沿用可见敌人 23–32 米的使用范围，避免原先连续消耗全部手雷。

受伤期间不会读取隐藏敌人的实时位置来部署烟雾。治疗依据投掷时记住的威胁位置，敌人仍可能绕过烟雾或射入烟中；机器人没有无敌保护。近地投掷仍可能受地形、碰撞和移动惯性影响，未实现通用投掷轨迹规划或团队烟墙。

战术计时是可重算的临时状态，单机续存后重新决策；实际库存、治疗动作、飞行中的投掷物和烟雾仍沿用现有存档。单机和专服执行 AI，在线客户端只接收已有的权威同步。

验证：`tests/bot_utilities_rules.gd` 使用真实刚体和烟雾生命周期验证掩护治疗、库存、冷却、掩体/进圈优先级；`tools/test_bot_utilities_network.py` 用专服机器人实际拾取烟雾物资，并由真实客户端观察投掷、起烟和治疗同步。
