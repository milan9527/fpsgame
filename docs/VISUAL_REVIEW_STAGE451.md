# Stage451 — 山群布局重构与当前版本人物复审

本轮基于实际 Stage450 检查点；保留工作区已有未提交修改。Stage446 已处理道路横向修补矩形，450 当前截图仍有光滑山壁与重复环状山群。因此本轮修改环境的空间结构，不再只调整峰顶系数。

`client/scripts/world.gd` 将18个等间距环状山体替换为11处手工布局的主山、前景支脊、远处分水岭与北侧低鞍部。位置、半径、高差和方向共同定义；背景树根仍读取山体元数据对应实际高度场。未重新修改山峰高度函数。

本地启动：`artifacts/realism451-preview/Linux/launch.sh`。
当前 PCK SHA256：`ada170a421d25628505e10619e5b09cc216ff5209cf8c2c0c3a43f78450628ed`。

## 本轮证据范围

450与451均重新捕获入口近景、宽幅地形和道路远景。相机位置、朝向、截图及过程状态分别保存在 `artifacts/realism451-validation/before/` 与 `after/`；对照审核见 `comparison-audit.json` 与 `comparisons/`。

人物使用451包运行完整默认、瞄准、换弹中段、换弹结束四姿势，不传单姿势筛选；另采样SG/SR及第三人称站立、蹲姿换弹中段。静态采样与弹药断言不能证明连续动作自然；拔匣、插匣、回握全程与第三人称移动过程仍未覆盖。本轮未执行联网验证，不能沿用旧版本通过结论，也没有证据将其标为认证故障。

## 人物审阅

完整四姿势捕获退出0，`poses/process-result.json` 的筛选列表为空且 passed=true，耗时796.865秒；四张均已逐张查看。默认持枪的前臂细长，袖口和手套连接突兀；ADS视线可用。AR换弹中段可见圆片状指节和薄钩状拇指，结束时弹药恢复30、左手回到护木附近，但部分接触面被遮挡，不能认定握持自然。

SG与SR换弹中段均已查看：两条腕部细长，袖口粗厚，右掌贴握把处呈圆片/钩片，左手持匣也有明显圆片指节。SR枪托与机匣大面积平滑面仍显简化。不能把手与武器重叠视作接触自然。

`contacts/process-result.json` 正常退出0，四张采样通过，耗时890.134秒；第三人称站立、蹲姿也已逐张查看。肩部与胸前装备之间的连接僵硬，肘部呈团块弯折，脸与靴子缺少结构。站姿左手垂到腰侧；蹲姿手、弹匣与护木接触被武器和膝部部分遮挡，不能据此判断插匣或回握正确。蹲姿图远处一个角色离地，单帧无法区分跳跃与悬空缺陷，需后续连续观察并检查落地。上述通过仅指捕获与脚本断言，画质和动作自然度未通过验收。

下一次人物修改应从前臂整体截面、腕掌体积与袖口过渡共同处理，而不是继续平移手掌或微调单根手指；同时检查第三人称肩肘体积与动作弯折。连续拔匣、插匣、回握、移动与切枪过程仍需实机连续证据。环境方面继续处理坡面形态与材质、植被层次、路肩过渡及建筑内部设备与光照，不能以远山退后代替这些目标。
