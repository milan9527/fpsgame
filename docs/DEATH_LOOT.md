# 淘汰物资

权威服务器或单机世界在淘汰时，将参战者剩余物资转移至淘汰位置：储备和三枪已装弹药合并为弹药补给，医疗包、剩余护甲、手雷分别保留数量。已受损护甲不会恢复；已投出的手雷不在库存中。原来的固定 45 发奖励已移除，空库存不会生成物资。

物资转移后清空尸体库存。重复伤害或重复调用不会再次产生物资。每回合使用递增编号，避免玩家编号和机器人编号取绝对值时碰撞。未取物资保留至回合结束，新回合清理。

类别按颜色在同一位置堆放。按 E 按现有附近补给规则取用，或按 B 从背包的附近物资列表逐项选择；库存上限、余量、遮挡与距离检查仍生效。断线淘汰也走同一路径。目前没有按尸体分组的容器界面，也不转移枪械、配件或不同口径弹药。

`tests/death_loot_rules.gd` 验证实际淘汰、守恒、部分拾取、重复调用、编号、空库存、视觉尺寸和回合清理。`tools/test_death_loot_network.py` 使用真实鉴权客户端、专服和可靠操作验证死亡物资数量同步、部分拾取、重放拒绝及取完后的实体移除。
