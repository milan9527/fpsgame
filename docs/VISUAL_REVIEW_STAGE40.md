# Stage40：SR目镜镀膜与分划

本轮基于stage39继续处理第一人称武器。新增随枪体运动的透明圆形目镜表面、边缘遮光和细分划，中心留空供已有HUD瞄点显示。切换武器会移除旧目镜，投掷/治疗期间跟随武器隐藏。未修改手臂几何、弹道或缩放规则。

## 实际画面审阅

独立开发预览从项目外运行，固定相机1280×800，Forward+ / llvmpipe。三武器腰射/ADS六张，加SR换弹25/50/75%三张，原图在 `artifacts/realism40-preview/capture/`。汇总 `artifacts/realism40-comparison/contact-sheet.png`；同相机stage39/40 SR前后对照 `artifacts/realism40-comparison/sr-before-after.png`。

已实际查看九图汇总、SR全尺寸ADS和前后对照：腰射不再是纯空洞镜口，ADS分划与中心瞄点对齐；换弹中镜片随枪旋转，未看到游离方片。AR/SG腰射与ADS形态保持。镜片边缘蓝灰光晕仍偏雾状，不能称为真实光学效果。当前仍用整屏FOV缩放，没有独立镜内放大；刻度未做弹道标定。

枪体金属/聚合物区分仍弱，手指包握简化、部分手套形体像整体块，建筑重复、地面草丛分布机械和整体光照平淡仍明显。本轮没有解决人物、手臂与大场景质量，整体目标未完成。

## 验证和限制

`artifacts/realism40-validation/` 保存瞄准108样本、装填接触183样本、外观挂点及远端快照、遮挡碰撞规则和独立包单机16角色烟测PASS日志；快照测试不代表真实联网通过。新增目镜数量、位置、隐藏及切换清理断言。初次外观测试遗漏切换后的渲染更新，补齐后通过，原失败日志保留。

初次并行截图武器0虽写完两图，但退出1并出现static string清理报错；武器1退出0但有NO GRAB。两进程使用同一X显示器，疑似显示器生命周期冲突，不能仅据此证明根因。改用独立显示器分别重跑，最终结果见verification.json和对应retry日志，原始失败日志保留。

本地入口 `artifacts/realism40-preview/Linux/IronMeridian`，需同目录PCK，说明和哈希清单在预览目录。仍是Godot4.4.1引擎+PCK开发预览，缺少release导出模板；软件渲染不证明实体GPU性能。真实联网此前认证HTTP404未解决，本轮未重测。未推送或发布。

下一轮优先区分枪体金属、聚合物和橡胶材质并细化手指包握，沿用相机复查腰射/ADS；随后继续人物、建筑、地形植被光照和真实联网问题。
