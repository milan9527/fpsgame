# 0.37.0-dev 运行服务升级

本次开发发行将机器人平坦开放区域转向驾驶与下车碰撞修复加入默认 Linux 包和运行服务。版本为 **0.37.0-dev / 协议 17 / ash-valley-18 / 数据库 0004**。完整商业级游戏目标仍未完成。

机器人可选择经过车体包络和地面检查的弯曲路线，以较低速度驶向目标。修复包括下车车体跳位、持续疾跑穿入车体，以及车体移出场景后人物无法移动。复杂道路寻路、绕障、倒车脱困和完整协作驾驶仍待开发。

## 运行与版本

- 发布 API：`http://127.0.0.1:8000`；单人/双人专服 UDP 27015 / 27022。
- 独立开发 API / 双人专服：8001 / UDP 27031。
- 默认包：`artifacts/IronMeridian-Linux-x86_64.tar.gz`；解压后在 Linux x86_64 桌面运行 `./play.sh`，需要 OpenGL 3.3。
- 离线 SOLO/DUO 无需账号；在线客户端须与服务的完整版本信息匹配。

候选源提交 `967bc7d9281691b12fc9e6c788c93b23b6649458`，包大小 63,206,876 字节，SHA-256：
`68321608692a9c4702698dfc9b3a1fd44ce7bcaf2bc9f62b3924ae438b4e9e7e`。
旧 0.36 包和运行目录保留在 `artifacts/releases/0.36.0-dev/`。包内文档反映候选构建时点；当前部署状态以本发行记录为准。

## 验证范围

候选通过导入/导出、45 项包内规则、重新解压启动、四项实际渲染和 95 项后端隔离测试。专服镜像运行文件与候选一致；新后端在隔离恢复数据库上的幂等启动保持已有数据完整。

打包客户端验证包括连续两轮邀请入场、四客户端组队救援/标点/合成语音/战绩落库、左右转向乘车、丢包和上行中断下的载具观战、行驶中账号撤销与强制断线，以及 30 FPS/单向 30 ms 下的移动交火。solo/duo 自然对局分别约 101.4/117.85 秒完成结算，两场均未观察到机器人驾驶。详细范围与限制见 [候选记录](CANDIDATES.md)。

发布切换由 `tools/publish_candidate.py` 执行：检查玩家、预约和结果队列，创建最新备份，保留旧镜像与包，等待旧房间租约过期后使用固定镜像启动。`artifacts/release-0.37.0-dev/verification.json` 记录切换与数据指纹；该目录的 `solo-clients.log` 与 `duo-requeue.log` 记录发布端口单人同步及双人连续两轮入场通过；`post-release-restore.json` 记录切换后新备份的隔离恢复通过。

继续运行固定镜像：

```sh
docker compose -f compose.yaml -f artifacts/release-0.37.0-dev/compose.override.json up -d --no-build
```

服务配置自动重启，使用原 PostgreSQL/Redis 数据卷。物理音频设备、公网长时间体验、大规模真人并发及全部商业级功能仍未验收完成。
