# Stage100 第一人称握持复核

本轮调整 `tools/build_viewmodel.py` 的支撑手拇指中心线、虎口体积和袖口收束，重新生成 Blender / GLB。这是局部修正，尚未达到 stage31 要求的第一人称形体与材质实质提升，整体目标继续。

## 实际画面观察

- 固定人物位置和朝向，分别采集三把武器的腰射、ADS、换弹 25% / 50% / 75% 姿态。ADS 使用游戏自身的视场变化，因此与腰射的构图缩放不同。
- 已查看源码侧三枪十五姿态总览，以及卡宾枪腰射、ADS、换弹中点原图。`stage99-100-grip-comparison.png` 提供前后局部对照：拇指弧线稍低、虎口稍饱满，但变化有限，手指仍有管状环的观感；袖管细长，袖口接缝仍明显。
- 卡宾枪 ADS 红点处于画面中心，镜框没有被本轮手部调整遮住。换弹中点可见支撑手持弹匣；离散姿态截图和接触规则测试不能证明整个动画没有手指穿模。
- 枪体和握把仍偏厚重，金属、聚合物与手套的材质区分不足。建筑重复、植被分布机械、地面平坦、光照层次弱，人物本轮未作新的画面验证。不能将这些截图视为接近目标画质的证明。

使用 Forward+ / llvmpipe 软件 Vulkan；硬件 GPU 性能和真实双客户端联网未验证。网络状态规则测试不等于联网联调。导入退出码为 0，但仍有 `Parameter "t" is null` 报错，尚未解决。
