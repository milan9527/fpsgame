# Weapon attachments

The vertical foregrip is a collectible attachment for AR-30, SG-8 and SR-5. Four of Ash Valley's original ammunition positions now contain foregrips. The world supply has a purple marker and the original Blender foregrip model. Pick it up with the ordinary loot interaction or the inventory list.

Each weapon has one independent grip slot. Open inventory, equip the desired weapon, then choose INSTALL FOREGRIP or REMOVE FOREGRIP. Installed weapons display `+ GRIP`. Carry up to three spare grips; installed grips do not use spare capacity. Removal requires a free spare slot. Spare grips can be dropped in chosen quantities. Death drops both spare and installed grips and clears the corpse's attachment state.

An installed grip reduces that weapon's per-shot recoil increment by 20%. Base spread, damage, ammunition capacity, recovery rate and maximum accumulated recoil are unchanged. Existing crouch recoil reduction stacks multiplicatively. Changing attachments is blocked while reloading, healing or throwing. Bots can collect and install a grip on their equipped weapon.

The server owns installation and stock changes. Reliable channel 4 carries the round ID, shared action sequence, current weapon index and explicit install/remove choice. Duplicate, stale, wrong-round, invalid, dead-player and over-budget requests cannot change inventory. Snapshots include three grip-slot values and spare stock, so other players see the attached model. Protocol 12/content `ash-valley-17` rejects older network clients.

Offline checkpoints preserve all slots and stock. A checksum-valid format-1 `ash-valley-16` checkpoint can migrate by adding empty slots and zero spare grips; its round ID, original loot and all other state remain intact. Migrated state still undergoes full validation. Other older content revisions remain unsupported. No new supplies are injected into resumed old rounds.

Original assets: `art/foregrip.blend`, `client/assets/foregrip.glb`, generated by `tools/build_foregrip.py`. The grip appears on first- and third-person weapons. Dedicated hand gripping/IK and installation animations are not yet implemented. This release includes one attachment type, not optics, magazines or muzzle-device customization.

Validation: `tests/foregrip_rules.gd` covers inventory conservation, slot separation, recoil, model presence, snapshots, checkpoint disk resume/previous-version migration, death drops, capacity, replay and action gates. `tools/test_foregrip_network.py` runs a dedicated fixture and two real clients, checking inventory actions and the observing client's model state.
