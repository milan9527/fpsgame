# 战场背包

存活且对局进行中按 B 打开背包，按 B、Esc 或返回按钮关闭。左侧显示储备、医疗包、手雷、护甲和三枪独立弹匣，可点击切枪、换弹或治疗。右侧显示 2.8 米内无遮挡的物资，包括淘汰物资；点击指定行取用该物品，满库存时禁用，部分取用显示剩余数量，物品消失时移除行。

背包不会暂停单机或在线对局。打开时释放鼠标并发送中立移动/射击输入；死亡、回合结束、返回菜单或进入暂停菜单时关闭。Esc 优先关闭背包，再次 Esc 才打开暂停菜单。关闭时若仍按住鼠标，需要松开后重新按下才能开火或瞄准，避免把界面点击变成射击。

背包按钮复用可靠操作通道与服务器规则，不在客户端修改库存。拾取传递明确目标编号；服务器重新检查存活、回合、距离、遮挡、容量、操作序号和限流。切枪、换弹、治疗沿用现有时间与库存限制。单机按钮也执行相同的操作校验。

目前使用固定三枪和按类别计数的物资栏，尚无拖放、主动丢弃、重量容量、枪械拾取替换、配件或不同口径弹药。

`tests/inventory_rules.gd` 覆盖实际按钮操作、指定物资、部分拾取、武器/换弹/治疗、输入隔离与关闭生命周期；`tools/test_inventory_network.py` 验证真实鉴权客户端通过背包选择医疗包和弹药、库存同步及切枪。
