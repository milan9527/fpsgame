下载后开始游戏

  1. Windows：右键 ZIP 选择“全部解压”，打开文件夹，双击 IronMeridian.exe。无需安装 Godot 或运行脚本。
  2. Android：下载 APK，允许浏览器安装此应用，安装后打开“铁境行动”。横屏使用触屏摇杆和按钮，无需运行脚本。新版登录成功后自动记住账号密码，可用 FORGET LOGIN 清除。
  3. Linux：解压安装包，在游戏目录执行 ./play.sh --max-fps 60。
  4. 单机直接选择离线模式，无需账号。
  5. 联网时在游戏内创建账号或登录。Windows 和 Android 客户端已预填以下服务器地址；Linux 客户端请填写：
正在获取服务器地址…

账号操作全部在安装后的游戏内完成，本网站不收集用户名或密码。联网无需 SSH 转发。
