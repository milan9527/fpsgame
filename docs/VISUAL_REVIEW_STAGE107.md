# Stage107 环境材质审阅

本阶段修正棚架钢材误用岩石纹理，以及地坪外围连续黄色矩形沉积带。钢架改为灰绿色不透明漆面；碎石带通过世界坐标噪声改变宽度、断开沉积，并在通行处留缺口。没有改变建筑碰撞几何。本阶段是环境局部修正，整体写实目标仍未完成。

## 实机观察

- 普通接近机位与棚架近景中，钢柱不再呈现岩石斑块，材质更符合涂漆钢构件，但表面仍过于洁净。
- 地坪外围黄带减弱、断开；部分黄褐色斑块和笔直的地坪接缝仍可辨识，不能认为地表融合已经解决。
- 宽幅地形仍暴露大面积空旷院区、重复草型、圆滑山体和稀薄树冠。本阶段没有解决植被形态和光照层次。
- 入口近景坡道有明显强反光，混凝土颗粒也偏突兀，应优先修正。
- 第一人称前臂仍显得细长，腕部过渡需要继续实机审阅。第三人称人物尚需独立复核。

## 验证范围及限制

测试覆盖瞄准、武器阻挡、单机冒烟、入口和屋顶碰撞、联网状态逻辑、棚架净空和掩体边界，以及仓库与棚下双向通行。仓库通行保留地坪碰撞。入口截图、四个固定环境机位和三把武器的持枪、瞄准、换弹截图用于回归审阅。

验证中进程三次以 143 退出，原因未确定；恢复脚本保留已经通过的记录并重跑未完成检查。最终结果以 `test-results.json` 和 `verification.json` 为准，不能将中断当作通过。

最终 28 条验证记录全部通过，最终日志未检出 ERROR/WARNING，基线、源码及打包版本环境相机数据一致。48 张 1280×800 原始截图用于核对采集完整性，不代表画质达标。已实际审阅四机位前后对照 `environment-before-after.jpg`、入口及宽幅地形原图和打包武器联系表 `packaged-weapon-contact-sheet.jpg`；钢架与沉积带改善可见，入口反光、地表硬接缝和植被重复仍需继续处理。

渲染使用软件 Vulkan llvmpipe，不代表硬件显卡性能。联网状态测试不等于真实认证多人联机；真实多人仍未验证。预览为 `artifacts/realism107-preview/Linux/IronMeridian` 和同目录 PCK，启动方法见预览 README。
