# Stage61 第一人称指腹、拇指和皮革分区自审

本轮接续stage60，针对stage31提出的第一人称形体问题继续修改。本报告为开发进程自审，整体目标未完成。

## 修改

`tools/build_viewmodel.py` 将手指圆管截面改为扁平圆角截面，增加周向采样，使用连续传递的截面方向避免弯曲处突然扭转。皮革面直接分配在手指网格上，关节处保留织物弯折区；收薄双手拇指根部，调整支撑手拇指弧线。已重建Blender和GLB。枪械本体、骨骼和握持锚点沿用当前检查点。

## 截图与判断

`artifacts/realism61-validation/after/` 保存三武器各腰射、ADS、换弹1/4、1/2、3/4姿态。固定角色位置(17,0.05,50)、yaw=atan2(-18,16)、pitch=-0.03；ADS使用游戏实际视场。`carbine-before-after.png` 为stage60/61同相机、同裁切对照，`all-poses-review.png` 为姿态总览。原始截图1280×800，Forward+、Xvfb、llvmpipe软件Vulkan，来自工作区图形运行。

对照结果：换弹暴露的指腹变扁、拇指根部收薄，连续圆管感有所减轻；仍有程序化手套轮廓及突出的袖口。腰射和ADS变化很小，手部大多被武器遮挡，不能称第一人称画质已达标。三武器瞄具维持居中；离散截图不能证明全动画无穿模。枪械平直机匣、重复仓库、稀疏草地、简化山体与远景树仍明显，本轮未改善第三人称人物、环境或光照。

## 验证

- `tests.json`：六项回归通过，包含108个瞄准样本、183个换弹接触样本、抵墙规则、第一人称动作、手套材质/UV及三武器模型规则。接触测试检查锚点，远端快照规则也不等于真实联网。
- `packaged-smoke.log`：独立用户目录运行导出包，16演员单机烟测PASS，覆盖换弹、治疗、受伤、胜利、射线、掩体、射击间隔和骨骼。未进行完整人工移动碰撞巡检。
- `import.log` 仍有 `Parameter "t" is null` 导入错误；导入进程和导出退出0，截图及包烟测成功，不能称日志无错误。软件渲染不代表实体GPU性能。
- `network-probe.json`：本机8000端口 `/health`、`/protocol`、`/openapi.json` 全部404，真实联网未验证；未修改后台服务。
