# stage128 环境改造与实机审阅

本轮沿用环境优先级，改善中景建筑用途识别、远山轮廓、局部草斑与日照方向。整体目标仍为 continue，不能据此认定达到写实 FPS 目标。

## 实施

- `world_visuals.gd`：在 (-42,0,-35) 既有建筑增加带立柱、屋面筋条的外挑雨棚、分层烟囱和入口暖光。保留中央通道；雨棚、立柱及烟囱具备碰撞。
- 在 (-28,-25) 周围加入边缘受噪声扰动的草地恢复斑块，沿用已有障碍排除逻辑。
- `world.gd`：提高外围山脊并使高度随角度变化，打破上一阶段过低的连续地平线；调整太阳方向，保持原有能量。

## 审阅结论与局限

宽景和普通出生机位中，远山在树线以上的轮廓更清楚，日照改变了仓库墙面亮暗及投影方向。西车间入口本身几乎没有变化，不能计作新的建筑改善。新建筑附件的近景改善应与宽景中的实际辨识度分开判断。

新雨棚入口对照中，外挑屋面、两侧立柱和后方分层烟囱明显改变建筑轮廓，中央门洞和贯穿通道保持可见，入口出现暖色亮部。但宽景里的这些构件仍很小，雨棚本身偏暗且几何感较强，砖墙主体仍是规则方盒。入口中央地面依旧裸露平坦，新增草斑在这组取景中缺乏明显辨识度，不能将代码中的植被改动直接视为已证实的显著画质提升。

前景地形仍偏平，工业建筑仍有规则盒状体量，草丛与树木重复，手臂偏暗且折面明显。局部草斑不是整个植被系统完成；提高山体也没有解决全部纵深和材质问题。本轮未重新验证第三人称人物及完整第一人称动作序列。

## 验证及预览

`functional-results.json` 的十项回归及单机冒烟均退出 0，独立日志均有 PASS 且无脚本错误。覆盖五处建筑角色通行、32 处入口雨棚及 96 次底部射线、12 处屋顶、108 样本瞄准、武器遮挡及本地网络状态规则。16 角色单机冒烟通过装填、治疗、伤害、胜利、射线、掩体及射击间隔检查。

新增 `utility_station_traversal_review.gd` 的扩展验证见 `utility-station-collision-result.json`、`utility-station-collision.log` 和 `utility-station-traversal.json`：建筑前后门双向可穿行；角色撞到新增立柱后停在 z=-23.84168；向上射线命中雨棚 y=3.489565。未把截图冻结场景当作碰撞测试。

本地网络规则测试不能代替真实双客户端认证联机；本轮未完成真实联网验收。
