# Stage110：混合草型、室内钢梁与吊灯

本轮在正常游戏机位改善植被轮廓和建筑内部结构。整体写实目标仍未完成，不能以采集数量或测试通过代替画质判断。

## 实施

- Blender 生成低草、细长杂草、阔叶地被三种网格，替换单一草丛；结合原有覆盖噪声选择种类，按网格区域及种类合批。保留建筑障碍周边排除区域。
- 仓库内部增加工字梁腹板、翼缘、檩条及墙边连接件；吊灯降低并增加吊杆，向下聚光同步降低。结构位于角色头顶上方，不给装饰梁增加地面障碍；原有墙、地板、门口碰撞保留。
- 增加室内平视偏下机位，检查灯具、地板照明和通道；旧版109与新版110使用相同采集脚本。

## 实机审阅

宽幅地形中，近景低草之间出现细长叶片和阔叶簇，单一刷子状重复有所减少。但叶簇仍较程序化，局部绿色噪点密集、接地阴影弱；院区空旷、树木重复、山体平滑等问题仍在。

入口近景及室内机位中，原来整片平屋顶增加了明确的横梁、纵向檩条和连接件，吊灯离开顶板后更容易辨识。平视机位能看清室内地面和出口，未发现新增灯具被梁完全遮住。室内墙面仍过于均匀，木箱纹理模糊且体块突出，坡道条纹仍像木纹，下一轮应优先处理材质尺度及布局。

本轮没有修改武器和人物；第一人称细直腕部、握持和换弹接触、第三人称人体仍需继续审阅及修正。静态姿态截图不能代替连续动画或实际联网验收。

已单独查看 AR-30 的正常瞄准和半程换弹原图：瞄准红点位于画面中心，建筑入口及近景植被可辨识；半程换弹下的右腕仍显得细长，手臂轮廓和弹匣握持需要后续连续动作审阅。环境变化没有消除这些人物表现缺陷。

## 验证边界与诊断

单机通行使用实际角色物理步进，仓库前后门及棚下通道双向测试，未禁用地板。网络检查仅覆盖状态规则，真实认证多人未验证。渲染使用 llvmpipe 软件 Vulkan，不构成硬件GPU性能结论。

实现期间一次过宽文本替换误改了无关合批函数，导入日志检出了未定义变量；已修正，并使用绝对路径重新导出最终PCK。保留早期失败日志，不将其当作最终通过证据。一次采集进程退出143，恢复时仅沿用已有通过项，其余重跑。

本地运行：`./artifacts/realism110-preview/Linux/IronMeridian --path /tmp --rendering-method forward_plus`。需要图形显示和 Vulkan，保留同目录 PCK。未推送或发布。

## 最终验证结果

最终29项导出、采集及测试记录全部通过，见 `artifacts/realism110-validation/test-results.json`；`verification.json` 保存相机一致性、图像尺寸及文件哈希。旧版、源码版和打包版的环境及入口相机参数完全一致。57张原图用于保存本轮证据，不代表画质达标。最终绝对路径导出日志为 `reexport-fixed-absolute.log`，早期诊断失败日志另行保留。

源码与打包版均通过瞄准、武器遮挡、单机烟雾测试、入口/屋顶/掩体碰撞和仓库/棚下双向角色物理通行。仓库沿 x=35 从 z=44 到24.974、反向24到43.026；棚下沿 x=23.5 从44到18.425、反向18到43.575，均保持地板碰撞。网络状态规则通过，但不能据此认定真实多人功能通过。

已审阅同机位环境对照及打包版入口、宽幅地形、室内地面原图，并查看三种武器姿态联系表和单独瞄准原图。新增钢梁、吊灯和混合草型在实际视角可见；仍保留上述材质、重复场景、人物握持及动画缺陷。下一阶段先改货箱、坡道材质尺度与植被接地感，再结合第三人称及连续换弹审阅安排人物修正和真实联网验收。
