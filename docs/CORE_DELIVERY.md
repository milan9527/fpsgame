固定服务启动命令：

## 使用边界

联网验证使用真实独立游戏进程和 ENet，但客户端运行在同一主机；当前 API 只监听本机，**未交付已验证的公网游戏地址**。其他电脑接入须部署可达的 API/UDP 地址，见 [远程接入说明](OPERATIONS.md#远程玩家接入)。不能在另一台电脑上把 `127.0.0.1` 当作本服务器。

地图与内容规模有限；没有百人大战、多地图、完整商业运营系统或已验证的公网长期负载能力。真正断线重连、物理麦克风实测和进一步画面打磨属于可选后续工作，不作为本次核心功能交付的条件。

当前分支还保留已测试但未打包的登录表单改进、默认关闭的角色保留及重连接口代码。交付版本不包含这些变更，不能将其表述为已发布功能。

后台游戏服务和定时备份独立于 Codex 界面运行，依赖宿主机与 Docker 持续可用；这不意味着界面退出后 AI 可以持续开发。
