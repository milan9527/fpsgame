# Stage90：收紧第一人称袖子与袖口

本轮接续 stage89，针对 stage31 优先改善第一人称的要求，实际重建袖子形体。整体写实目标仍未完成，不能把本轮缩形视为人物、武器或场景已经达标。

## 改动与同机位证据

`tools/build_viewmodel.py` 收紧远端前臂、减弱腕部鼓包和褶皱位移；末端袖子半径从 36mm 改为 31mm，袖口半径范围由 41→29mm 改为 35→27mm。重新生成 Blender 与 GLB。手掌、武器与握持锚点未调整。精确改动范围记录在 `artifacts/realism90-validation/geometry-change.md`。

`artifacts/realism90-validation/wrist-before-after.jpg` 是 stage89 与 stage90 同机位原截图裁切，显示腰射左前臂更窄、换弹右手腕附近的鼓包减弱。不是材质全面升级。`source-aim-pairs.jpg` 覆盖三种武器的腰射和 ADS；`source-reload.jpg` 覆盖三种武器的三个换弹采样点。截图位置 (17,0.05,50)、俯仰 -0.03；ADS 按游戏正常缩放，位置与朝向一致。

审阅中三种武器的瞄具仍可见，袖子没有明显新断口，抽样换弹姿态未见缩形造成的明显手套脱节。但左手掌仍像厚片/连指手套，右腕到前臂仍偏长管状，袖子的大面积褶皱缺少真实缝制结构。AR 机匣与其他枪身仍有过于平直、材质分层不足的问题。远景建筑重复、草丛分布规则且缺少地表层次，环境空旷和光照平淡仍然明显。

## 验证与边界

源码和独立 PCK 预览分别执行七项检查：手套材质规则、瞄准对齐、换弹接触、近墙遮挡、视图模型、武器外观和单机冒烟，共 14 项。具体退出码和 PASS 记录以 `artifacts/realism90-validation/test-results.json` 为准。瞄准每版本 108 采样，换弹接触每版本 183 采样。源码与预览各采集 15 张 1280×800 实际 Forward+ 截图，索引和哈希见 `capture-index.json`，过程退出码见 `verification.json`。

源码与包内两次完整采集均退出 0 且输出 15 帧 PASS。已实际审阅包内 `packaged-aim-pairs.jpg` 和 `packaged-reload.jpg`，上述轮廓改动及剩余问题与源码一致；15 对截图的各通道平均绝对差最大为 0.725/255，这只用于核对预览一致性，不代表画质评分。

Blender 构建、Godot 导入和 PCK 导出退出码均为 0；导入仍输出已有 `Parameter "t" is null`，不能称为完全无错误日志。截图采用 llvmpipe 软件 Vulkan，未测硬件性能。远端快照规则不等于真实联网，本轮没有实际多人会话验证；近墙武器遮挡也不等于全地图碰撞巡检。人物全身与建筑/植被没有在本轮完成专项审阅。

本地预览：`artifacts/realism90-preview/Linux/IronMeridian`，同目录配套 PCK；启动说明与构建哈希见预览目录 README.md、build.json。没有推送或发布。
