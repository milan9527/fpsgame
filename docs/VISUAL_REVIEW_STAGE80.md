# Stage80：手套贴合补片与三武器画面复核

整体目标仍为 **continue**。本阶段基于stage79的现有动画，修改第一人称手部资产；没有把材质微调视为写实目标完成。

## 实现与构建

`tools/build_viewmodel.py`为左右手各增加两块沿最终手部表面投射的薄皮革补片，保留手骨绑定、UV和外向法线。补片高度从边缘0.2毫米渐变至中心0.7毫米，避免独立椭球块浮在手背上。手套及皮革微法线强度分别从0.065/0.10降至0.016/0.025，皮革粗糙度提高并缩小噪声变化。重新生成`art/first_person.blend`、`client/assets/first_person.glb`及配套纹理。

第一次较宽补片在左手边缘投射未命中，构建被脚本异常中止，未导出该版本；失败日志保留为`blender-rejected-panel.log`。缩窄覆盖范围后的构建使用`--python-exit-code 1`并正常退出，`blender-build.log`包含资产PASS。导入退出0但仍报已有的dummy renderer纹理空参数错误，见`import.log`；不宣称该错误已修复。export-pack退出0，未出现ERROR。

## 实际画面结论

本轮使用实际游戏场景、固定相机、Forward+与Xvfb/llvmpipe软件Vulkan，截图脚本冻结游戏逻辑后驱动姿态；不等同于实体GPU性能验证或人工连续游玩。原始截图1280×800。源码拍摄卡宾枪五姿态；预览包扩大到三种武器各五姿态，避免只依赖卡宾枪结果。

- `comparison-hip-ads.jpg`：stage79/80同相机腰射与ADS。两者构图基本保持，未见新增明显遮挡；手部改动在全画幅中很细微。
- `comparison-reload.jpg`：半程换弹及固定范围放大。薄补片存在，但不足以消除掌面硬壳感。织物规则网格仍明显，不能声称已消除失真材质。
- 枪托、握把和机匣仍显扁平；腕部/袖口过渡偏硬。重复仓库、规则草丛、空旷地表及远树层次问题仍十分明显；第三人称人物本轮未复核。

## 验证范围

检查结果以`artifacts/realism80-validation/test-results.json`及`capture-status.json`为准。覆盖材质/UV、三武器108个瞄准样本、183个换弹接触样本、近墙枪口遮挡、视图模型状态、武器视觉结构、32个雨棚96条射线、16角色单机冒烟。remote_snapshot检查不等于真实联网。

现有`tools/test_smoke_network.py`会读取`.env`中的SERVER_SECRET并启动认证夹具，本轮未执行它、未读取密钥、未修改认证或服务。因此真实认证联网验收仍未完成；这不影响本阶段本地资产和离线验证，但不能以结构测试替代联网结果。

本地预览位于`artifacts/realism80-preview/Linux/`，以仓库Godot可执行文件与export-pack的PCK组成。标准Linux模板缺失沿用上轮已确认的环境情况，本轮没有重复尝试标准导出。构建哈希和验证索引见该目录build.json、verification.json。

下一阶段应重塑掌根、手指关节与袖口连接，降低规则织物网格的视觉干扰，并改善枪身聚合物/金属分区；继续同机位腰射、ADS和换弹对照。随后仍需推进人物、建筑差异、地表植被及光照，并解决符合密钥约束的真实联网验收路径。
