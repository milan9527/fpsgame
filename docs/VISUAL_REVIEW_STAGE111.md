# Stage111：仓库入口设施与地坪材质

本阶段继续环境优先，不代表整体写实目标完成。保留已有未提交修改，无推送或外部发布。

## 改动与实际画面

- `world.gd`、`warehouse_concrete.gdshader`：仓库室内地坪和入口坡道共用世界坐标混凝土材质，细颗粒、入口积尘及双轮迹按建筑局部位置分布。坡道和地板碰撞形状未改。
- `world_visuals.gd`：门外两侧增加齐地排水格栅、墙上配电柜、通风槽、把手与走线。通过已有设施合批路径生成，避开四米门洞；装饰没有新增阻挡。
- 实机入口斜视中，排水格栅和柜体能够辨认；原坡道木纹/岩粒感减弱。室内地板仍过于均匀，积尘与磨损的视觉强度不足，不能据此宣称材质已经写实。
- 本轮保留 stage110 的混合草、钢梁与向下照明，未新增植被或调整光源。宽幅画面仍有空旷道路、重复仓库、稀薄树冠、棱角山体和草簇接地弱的问题。货箱纹理仍模糊，暗绿大墙面仍需要材质和结构变化。
