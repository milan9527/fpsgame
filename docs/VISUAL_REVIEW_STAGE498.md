## 验证边界

所有本轮测试均调用 stage498 预览；不沿用 stage497 通过状态。环境使用 Forward+、1280×800，固定入口、宽幅地形、道路远景三机位。四姿势采样不使用 `--pose` 筛选；另采集 SG、SR 换弹中段与第三人称站姿、蹲姿换弹中段。它们只是实际引擎动作的离散帧，不能证明连续动作自然，也不能证明旧、新弹匣身份交接无误。

联网仅对本机 API 做只读预检：`/health` 和 `/protocol` 均返回 HTML 404，不能验证联网主要功能；没有尝试认证、改动后台服务或部署。
