# Iron Meridian 玩家指南

这是原创战术生存 FPS 的开发版本。当前有一张地图、16 人参战名额、离线机器人、单人混战及双人组队玩法。它尚不具备《和平精英》商业成品的全部内容和品质。本指南包含 0.35 开发候选版本的新功能；旧 0.34 发布包不包含双人模式和语音。

主菜单或暂停菜单的 **KEYBOARD CONTROLS** 可修改键盘操作。下文按键表为默认值；游戏内提示会随改键更新。

## 启动

Linux 桌面解压后运行 `./play.sh`，需要 x86_64、OpenGL 3.3 及桌面显示环境。首次运行不需要账户。开发环境可运行 `./tools/godot --path client`。

选择 **SOLO / OFFLINE OPERATION**，进入离线对局。地图上的其他参战者为机器人。离线对局不依赖后端或互联网。

单机按 Esc 打开菜单会真正暂停对局：机器人、缩圈、手雷、换弹、动画和声音都会停止。切到其他应用时也会自动暂停，回来后按 Esc 或点击 **RESUME** 继续。暂停时间不计入单局时长。存活时可点击 **SAVE OPERATION & RETURN** 保存并返回主菜单，之后用 **CONTINUE SAVED OPERATION** 继续。继续后先停在暂停菜单，按 RESUME 才推进对局。已有存档时保存按钮会显示 REPLACE。选择 ABANDON、直接关闭游戏或已被淘汰会结束该回合，旧存档不能用来重试已经结算的回合。

机器人可以绕墙并从门口进出建筑；丢失视线后会前往最后看到目标的位置，缺少物资时寻找附近补给，安全区缩小时优先进圈。

在线模式填写用户名、密码与 API 地址，选择创建账户或登录。用户名为 3–24 个英文字母、数字、下划线，密码至少 10 个字符。默认本地服务为 `http://127.0.0.1:8000`。远程服务地址由部署者提供。

大厅等待 18 秒后开始，空位由机器人补满。进行中的对局不允许中途复活加入；此时连入的玩家等待下一局。结算后 12 秒自动建立下一局。

在线 Esc 菜单不会暂停服务器，你的角色仍可能受到攻击；菜单中会明确提示。关闭菜单后恢复操作。

在线枪击有最多 200 毫秒的服务器延迟补偿。网络延迟较高时，刚进入掩体仍可能受到先前可见位置的命中；超过补偿上限的延迟不会继续扩大命中窗口。手雷按服务器实时位置结算。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 视角 | 鼠标 |
| 射击 / 瞄准 | 左键 / 右键 |
| 烟雾弹（需先拾取） | V |
| 奔跑 / 蹲伏 | Shift / Ctrl |
| 左探身 / 右探身（按住） | Z / C |
| 跳跃 | Space |
| 换弹 | R |
| 切换步枪、霰弹枪、精确射手步枪 | 1 / 2 / 3 |
| 拾取近处补给 | E |
| 使用医疗包 | H |
| 投掷破片手雷 | G |
| 在线双人按住说话（须先启用麦克风） | T |
| 本局记分板 | 按住 Tab |
| 暂停 / 对局菜单（在线不暂停） | Esc |
| 淘汰后切换观战目标 | Q / E |
| 观战环绕 / 距离 | 鼠标 / 滚轮 |

普通跳跃和约 3 米以内落地通常安全；从较高屋顶或高处坠落会直接损失生命值，护甲不减免坠落伤害。

按住 Ctrl 蹲伏，碰撞体、视点和开火高度一起降低；低顶下松开 Ctrl 会继续保持蹲伏，直到头顶空间足够。蹲伏时不能跳跃。画面右上角显示安全区与自身位置，不显示敌人。

## 战斗规则

- 治疗中再次按 H（或自定义治疗键），也可在背包点击 CANCEL MEDKIT，主动取消治疗；取消不回血、不消耗医疗包。详见 [医疗包](HEALING.md)。
- 每局最多 5 分钟，最后存活者获胜。达到时限时依生命值、击杀数和稳定角色编号顺序裁定。
- 伤害按服务器模拟顺序结算。若同一物理帧的多次伤害使全部角色死亡，最后被淘汰者保留第一名，结算文案和在线战绩采用同一结果。
- 开局有 5 秒伤害保护；35 秒后安全区逐步收缩，圈外持续受到伤害。
- 站立和蹲伏都有对应的头部命中区域。服务器确认命中后显示命中标记，爆头为金色、击杀为红色；受击时红色弧线指示来袭方向。
- 后坐力由服务器累计，连续射击会抬高弹道；停火后逐渐恢复。瞄准、蹲伏可以减小散布，移动则增加散布。
- 第一人称显示手臂、手套与袖口。右键将瞄具移至视线中心；换弹会播放支持手与弹匣动作，投掷后有手臂跟随动作，治疗期间暂时收枪。动作读取服务器状态，不改变实际消耗或完成时间。
- 三把枪有各自的模型，其他玩家也能看到你当前持有的枪。步枪、霰弹枪、精确射手步枪的瞄准视野分别为 48°、58°、24°，后者放大更明显、视野更窄。SG-8 使用可拆卸弹匣。
- 枪口空间被墙壁或掩体阻挡时，会收低武器并显示 **MUZZLE BLOCKED**，此时按下开火不消耗弹药。退开、转身或站起越过低掩体后恢复；长枪需要更多空间。
- 头部命中提高伤害；护甲吸收一部分伤害，耗尽后失效。
- 金色补给补弹药，绿色补给补医疗包，蓝色补给补护甲，橙色补给补手雷。
- 靠近补给时，HUD 显示 E 键可拿的物品及数量，选中物品会发光；隔墙不能拾取。装不下的物资保留原地，只装得下一部分时会留下余量。满库存提示 **INVENTORY FULL**。
- 按 B 打开背包，查看库存、切枪/换弹/治疗，点击右侧物资行拾取指定物品。背包中对局继续，Esc 或 B 关闭；关闭后松开鼠标再按可恢复开火。
- 背包右下方选择物资类别和数量，点击 DROP 丢到脚下，自己或其他玩家都可拾取。治疗时不能丢弃医疗包；弹药只丢储备，保留已装弹匣。
- 淘汰者会留下实际剩余弹药、医疗包、手雷和剩余护甲；按 E 拾取或从背包选择，库存满时保留余量。
- 三把枪分别保存弹匣，切枪不会自动装弹；按 R 等待换弹完成后，才从共享储备补充当前枪械。开局弹匣分别为 30/8/5 发，另有 120 发储备。HUD 小行显示三把枪的装弹量。
- 医疗包引导 3.5 秒，被伤害打断；换弹和治疗期间不能开枪。
- 在线操作由服务器裁定。本地移动先预测，再根据服务器校正；网络抖动可能造成位置修正。开火命中尚无延迟补偿，高延迟仍会影响枪战体验。
- 在线战绩保存至 PostgreSQL，提交失败时服务器落盘重试；离线战绩当前不计入在线排名。
- Esc 菜单不会暂停战局。

淘汰后自动进入第三人称观战，可以观看本局任何存活参战者（包括机器人）。镜头跟随目标，遇到墙壁会收近；目标淘汰或离开后自动切换。HUD 的生命、护甲、弹药和小地图位置显示当前观战目标，上方另行显示自己的名次。观战操作不会控制目标角色。新回合自动回到自己的第一人称视角；离线对局结束后通过 Esc 返回部署菜单。当前没有击杀回放、延迟观战或队伍观战限制。

音量、鼠标灵敏度和 API 地址在部署菜单设置并保存。密码和登录令牌不会写入客户端配置文件。

脚步随实际移动触发，道路/建筑与草地使用不同声音，蹲伏较轻。起跳、落地、换弹、治疗和拾取有状态反馈；附近玩家的动作使用空间音效，墙体会衰减直达声。命中提示仅由自己的确认反馈播放。淘汰观战时听音位置跟随观战镜头。菜单音量会同时调整已经在播放的声音。

部署菜单的 **SERVICE LEADERBOARD** 从在线服务读取排行榜。已有登录会话时也展示个人在线战绩。

**LOCAL OPERATIONS** 显示本机单机战绩，重启游戏后仍保留。正常结束或淘汰后返回菜单会保存名次；仍存活时中途返回或退出记录为 **ABANDONED**，不会算作获胜。页面展示最近 100 局，汇总包含全部可读取的本地记录，击杀与时长也包含中途退出的对局。

保存失败时会提示重试；退出游戏前可选择重试或明确放弃尚未保存的结果。损坏主副本时尝试备用副本，无法读取的记录会提示且保留原文件。本地记录不上传到在线排行榜。战绩与单机进行中存档分开保存；在线对局不支持本地保存继续。存储说明见开发文档 `docs/LOCAL_RESULTS.md`。

## 破片手雷

每局携带 2 枚手雷，最多携带 4 枚。按 G 沿视线方向投掷，服务器处理抛物运动、墙地反弹和 2.6 秒引信；不是按住烹雷。投掷动作锁定 0.7 秒，期间不能开枪、换弹或治疗。

爆炸半径为 9 米，伤害随距离衰减，会伤害自己。服务器分别检查身体不同高度到爆心的遮挡，完整实体掩体可以阻挡伤害，部分掩体减少伤害。附近手雷会触发 HUD 警告。没有烟雾弹、闪光弹或燃烧弹。当前按键后立即释放，第一人称播放释放后的跟随动作；尚无拔销预备和烹雷动作。

在线登录后自动分配仍在候场且有名额的房间。当前部署有两个独立房间；无房可用时短暂重试后返回提示。对局开始后不补入新玩家，断线重连尚未实现。

连接过程中可点击 CANCEL 返回菜单。客户端会尝试释放未使用的预留；取消后也可开始单机，旧连接请求不会把你重新切回在线游戏。取消部署不会撤销已完成的账户注册。

按 M 展开战术地图，查看道路、建筑、当前位置和安全区。左键设置个人路标，右键清除；HUD 显示水平距离。M 或 Esc 关闭，B 切换背包。地图中对局继续，路标虚线只表示方位，不是自动寻路路线。

## 基础训练

主菜单选择 BASIC TRAINING，按 HUD 引导完成移动、蹲伏、三个射击靶、弹药拾取、换弹、治疗、破片手雷、烟雾弹和地图标记。提示跟随当前键位设置。训练保护玩家免受伤害，可按 ESC 暂停或退出；完成后按 ESC 返回部署。训练不计入战绩，不覆盖已保存的单机行动。

## 受击方向

受击时，准星周围的红色弧线显示来袭方向，多个方向可短暂同时显示。相近方向的连击会刷新同一提示，约 0.9 秒后消失；弧线跟随转身旋转，表示受击当时的方向，不追踪敌人的后续位置。坠落和安全区等没有水平方向的伤害只显示边框反馈。

## 武器握把

拾取紫色标记的 FOREGRIP 后，打开背包并选择武器，点击 INSTALL FOREGRIP 安装；REMOVE FOREGRIP 拆回随身库存。三把武器各有独立槽位，已安装武器标记为 `+ GRIP`。最多携带三个备用握把，安装后每发后坐力增量减少 20%；换弹、治疗或投掷期间不能安装/拆卸。备用握把可丢弃，死亡时已安装的握把也会掉落。上一版本的可用单机存档可继续，但旧对局不会自动增加新配件物资。

## 双人组队（0.35 开发候选版本）

主菜单选择 **DUO / OFFLINE TEAM OPERATION** 可与机器人队友开始离线双人对局。16 个参战名额组成八队；队伍之间竞争，队友直接攻击不会造成友伤，自己的爆炸仍会伤及自己。队友尚能站立时，致命伤害通常使你倒地；倒地后可缓慢爬行但不能战斗，需在失血结束前获救。靠近倒地队友，按互动键 E 开始约五秒救援，完成后恢复 30 点生命；移动、受击、失去距离或视线等会中断。双人检查点可保留倒地与救援状态。

在线组队先选择 **DUO** 再登录。创建队伍、复制邀请给另一名玩家；对方登录后粘贴接受。两人均 READY 后，由队长 START。邀请码是一次性的，队伍约 15 分钟到期；加入失败可刷新状态。开发服务默认 API 为 `http://127.0.0.1:8001`，只适合同机测试，跨设备地址由部署者提供。客户端和服务器必须具有相同协议与资源版本；0.35 客户端不能连接旧 0.34 服务。

队友的生命、倒地和距离会显示在队伍面板及地图中。在大地图左键标点可向队友共享约 20 秒，右键清除自己的标点。淘汰后只能观战尚在场的队友；全队淘汰后不能借观战查看敌方。死亡但队友最终获胜，仍记为队伍胜利；双人战绩与单人分别统计。

结算页可 **RETURN TO PARTY** 返回原队伍。队长重置上次预约，两人重新准备后可再次入场。游戏尚不支持断线重连至进行中的回合；队伍解散或过期时需重新邀请。

## 队内语音（0.35 开发候选版本）

按 Esc 打开菜单，开启 **Listen to teammate** 收听队友。麦克风每次启动游戏默认关闭，需主动开启；返回对局后按住 T 说话，可在 KEYBOARD CONTROLS 改键。语音只发给当前队友，敌人不会收到。关闭收听即可静音队友，音量滑块与主音量共同影响播放。

**MICROPHONE SETUP** 可选择输入设备、调整增益并按住按钮进行本地电平测试。测试声音不会发给其他玩家，也不会在本机回放。无输入时检查设备和操作系统权限；出现削波提示时降低增益。打开菜单、背包、地图或切出游戏会停止发送。建议使用耳机；当前没有声学回声消除或噪声抑制。

虚拟设备采集、队内转发和播放已通过自动验证，物理麦克风及耳机听感尚待设备验收。候选包仍是开发版本。
