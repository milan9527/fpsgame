# Stage108 院区地表与入口坡道审阅

本阶段将仓库院区的整块混凝土表面改为混凝土、碎石和泥土混合材质。边缘通过不同宽度的沉积和透明轮廓过渡，通行带保留磨损车辙，停车线按世界坐标磨损。基础地坪与连接带略微错开高度，避免扩展后的表面重叠闪烁。入口坡道恢复世界坐标三平面纹理，移除不合适的粗糙度贴图并降低镜面反射。建筑和坡道碰撞几何保持原有形状。

## 实机观察与未解决问题

- 仓库普通接近机位中，原先蓝灰色的矩形地坪变为偏褐色的磨损院区，停车线由连续亮色变成断续旧漆。边缘不再完全切齐，但黄褐色泥带和直线布局仍可辨识。
- 入口近景的坡道不再是一块亮灰色反光板，纹理能够辨认；打包版本仍呈偏暗的褐色条带，近似木纹，与室内地坪衔接不自然。坡道纹理尺度、两侧面的法线及实际受光应继续核查，不能把反光减弱等同于材质准确。
- 近地面仍有较明显的均匀斑点，草丛仍是一种放射状模型。山坡圆滑、树冠稀薄、院区空旷的问题尚未解决。本阶段未新增植被模型或重新设计建筑布局，也未调整全局光照。
- 第一人称手臂比例、腕部过渡和换弹接触仍需继续审阅；第三人称人物尚未获得本阶段的新实机证据。货箱纹理模糊和非等比拉伸仍明显。

## 对照方式

基线使用 stage107 导出包；当前源码和 stage108 导出包使用相同采集脚本。四个环境机位覆盖普通接近、装卸棚、入口近景和宽幅地形，另有入口斜视、门前及室内三个机位。每组均保存角色位置、目标位置、yaw、pitch、眼高与 1280×800 视口信息，见 `artifacts/realism108-validation/*-forward/` 内的两个 `*-camera-poses.json`。原出生机位由 `original-spawn-camera.json` 记录。

静态截图冻结游戏处理；入口和棚下通行由独立物理测试实际移动角色验证。截图数量只用于采集完整性检查，不能作为画质结论。

## 验证与预览

最终结果见 `artifacts/realism108-validation/test-results.json` 和 `verification.json`。验证范围包括源码及导出包的单机流程、瞄准、武器遮挡、入口/屋顶/棚架碰撞、掩体边界、仓库及棚下双向物理通行，以及网络状态规则。

最终 29 条记录通过，51 张原始截图完整，基线、源码与包内的环境和入口相机记录一致，最终检查日志未检出 ERROR/WARNING。源码截图采集曾退出 143，保留中断记录并恢复补跑，未将中断计为通过。已直接审阅环境和入口前后对照、宽幅地形原图、包内三枪五姿态总览及卡宾枪 ADS 原图；这些验证不代表真实联网或整体画质达标。
