# Stage120：山坡受光与植被连续性

本轮接续stage119的西侧坡顶车间、入口和沿墙草带，处理固定宽幅机位暴露的山坡棱面、稀疏林带和碎散草丛。整体目标仍为continue。

## 实现

- 山体采样从64×64格提高到128×128格；光照法线从连续高度场中央差分生成，避免三角面边界直接决定受光。未改变太阳和雾参数。
- 远景树木高度查询同步使用128格三角插值，增加林带候选点并扩大噪声组团范围；保持竞技场之外的无碰撞远景性质。
- 地表草丛扩大不规则组团覆盖，保留道路、建筑和设施的既有排除区；建筑入口及屋顶几何沿用stage119。

## 可复核证据

`artifacts/realism120-validation/before/`来自stage119独立包，`after/`来自stage120独立包。两组使用同一捕获脚本，固定单机状态，记录脚点、相机yaw/pitch和目标点至各自`environment-camera-poses.json`。截图用于画面检查，实际通行另由物理角色路线测试验证。

重要机位：西车间入口脚点(-42,0.05,44)、目标(-42,1.9,34)；东仓入口(35,0.05,44)、目标(35,1.9,34)；宽幅地形(17,0.05,50)、目标(-46,12,-90)。实际朝向以JSON为准。完整对照图为`*-before-after.jpg`，左119、右120。

独立远景测试`background_scenery.log`：实际渲染山体网格临时转换为碰撞面，逐株向下射线检查，18座山体、2545株树（含562株幼树），最大树根误差0.000097米，全部远景树在竞技场之外。

`functional-results.json`记录13项检查全部以退出码0通过：瞄准、武器遮挡、单机冒烟、入口与屋顶碰撞、东仓净空及掩体、本地网络状态规则、东西仓库与服务院/棚架/水务区通行。首轮执行进程曾以143中断，缺少完整退出结果的3项已补跑；成功结论依据补跑后的完整结果。该中断原因未查明。

实机入口近景中，东仓敞开门洞、内外通路和顶部卷帘可辨识，箱体遮挡未堵住中央通道；物理路线另行验证，不能仅由截图认定碰撞正确。建筑与室内灯具为stage119已有成果。西车间接近机位中，新版山坡的三角棱面明暗减弱，林带覆盖更连贯，前景草丛更成片；泥土地表仍有重复噪声质感，草地边界偏突兀，场地和远处建筑仍显平坦、重复。本轮改善不构成整体写实目标完成。

## 限制与后续

宽幅同机位前后实图确认：主要可见变化来自远山受光和林带连续性，草丛覆盖变化较小；道路仍显过宽、空旷，远处平顶房排列重复，棚架前方地面仍有明显黄褐色块边界。下一阶段应优先解决这些中景问题，不能继续仅增加远景树木数量。

Forward+ / llvmpipe软件渲染截图不代表硬件GPU性能。山体网格数量提高，仍需硬件上的帧率和启动时间评估。真实认证联网缺授权fixture，本轮仅测试本地网络状态规则。第三人称人物与第一人称连续换弹/瞄准动作仍未完成审阅。
