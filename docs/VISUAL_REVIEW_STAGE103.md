# Stage103：右掌位置与手套表面

本轮沿用 stage31 的第一人称优先方向，在 stage102 文件基础上修改 `tools/build_viewmodel.py`，重建 `art/first_person.blend` 与 `client/assets/first_person.glb`。右掌抬高约 23 mm、向握把内侧移动 4 mm，调整指列展开和拇指控制点；织物增加打包的橄榄色编织底色，接触皮革降低粗糙度。枪体本身本轮未修改。

实际卡宾枪截图采用固定角色位置、朝向和各姿态标准视野：腰射与 ADS 共用位置/朝向，ADS 保留游戏原有视野变化。ADS 红点居中，手臂未挡住瞄具。换弹中右掌位置上移、手套与袖料的纹理区别可见，但拇指到握把的空隙仍明显，指列未形成可信的包握；不能将拓扑检查通过解释为解剖形体完成。枪体仍偏厚重、聚合物和金属区分弱，袖子褶皱和织物也仍显程序化。建筑与树形重复、地面草丛分布均匀且空旷，人物和整体场景本轮未改善。

验证及预览证据在 `artifacts/realism103-validation/` 与 `artifacts/realism103-preview/`。最终结果以 `test-results.json`、`verification.json` 和实际截图为准；同机位前后对照为 `stage102-103-carbine-comparison.jpg`。源码及打包版三枪的腰射、ADS、换弹 25%/50%/75% 截图分别位于 `source-forward/`、`packaged-forward/`。

最终核验：源码与包内各 11 项功能检查通过，加导出和两次截图采集共 25 条成功记录；30 张截图与 11 个构建文件哈希核对通过。已直接审阅两张 `forward-contact.jpg` 总览：三枪瞄具未被手臂遮挡，未见缺失手臂或黑色贴图；霰弹枪和狙击枪仍显厚重，共用右手姿势在换弹时尤其缺少自然包握。规则测试和截图不能替代完整交互游玩及真实联网验证。

构建过程中 Blender 联合手网格出现重复面诊断，构建器清理后最终保存网格检查无无效拓扑，四个动画片段存在，见 `build-viewmodel.log` 与 `topology.log`。Godot 导入退出 0 仍报告 `Parameter "t" is null`，见 `import.log`。图形验证使用 llvmpipe 软件 Vulkan，未验证硬件 GPU。网络状态规则不代表真实认证多人会话；本轮未进行真实多人测试。

下一步应按三把枪实际握把接触面重新建立虎口和逐指弯曲，避免继续仅整体平移手掌；进一步改善枪体截面和金属/聚合物响应，再验证同机位腰射、ADS、完整换弹。人物、建筑、地形植被、光照与真实联网验证仍需继续。整体目标未完成。
