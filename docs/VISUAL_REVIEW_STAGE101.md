# Stage101：托枪手掌骨与四指联动

本轮根据 stage31 的第一人称优先要求，修改 `tools/build_viewmodel.py`，重建 Blender 源文件与 GLB：延伸左手掌骨区到指根，缩短从掌面悬伸的指节弧线，调整四指粗细、长度差和屈曲皮革位置。握持末端与现有动画继续沿用。武器本体和材质本轮未改，不能宣称完成武器与手臂的整体写实化。

## 实际截图审阅

`artifacts/realism101-validation/stage100-101-grip-comparison.png` 将 stage100/101 的同像素裁切并排显示，包含卡宾枪腰射、ADS 和换弹中点。完整截图位于 `source-forward/` 与 `packaged-forward/`。

- 腰射：掌面较饱满，指根与掌面衔接有所改善，但四指仍像细管，拇指形成明显钩环；这是有限改善，不是写实手部已达标。
- ADS：使用同一角色位置与朝向、各姿态原生 FOV；红点仍居中，手掌没有新增瞄具遮挡。不同 FOV 的画面不能当作相同投影直接叠图。
- 换弹：保留原接触关系。完整卡宾枪换弹中点图中，右手对握把的包握不足，大握把与弯曲手指仍突出；规则测试通过不能证明视觉接触自然。枪体厚重、金属与聚合物区分不足，需下一阶段连同手部姿态一起处理。
- 场景：重复草簇、相似平顶建筑、远山灰白和树木轮廓重复仍明显。此次固定镜头不覆盖第三人称人物质量，也不证明完整地图审阅通过。
