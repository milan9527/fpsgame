# 淘汰报告

玩家被淘汰后，左下方保留致命一击报告，观战期间和本局结果页面都可查看。新回合、重新单机开局会清空报告。

- 显示攻击者、武器、爆头，以及最终一次伤害实际扣除的生命与护甲；过量伤害不计入已扣除数值。
- 子弹距离按服务器结算时双方位置计算并取整到米。破片手雷显示到爆心的距离，注明 `FROM BLAST`；自伤显示 `YOURSELF`。
- 安全区和坠落显示环境原因，不编造攻击者或距离。投掷者断线后造成的淘汰显示 `DISCONNECTED OPERATOR`。
- 在线报告由权威服务器通过可靠 RPC 仅发给被淘汰的客户端。报告附带回合编号，旧回合消息不能覆盖当前状态；死亡快照与报告到达顺序不影响最终展示。

这是一份致命一击说明，不是录像回放，也不统计整场交火累计伤害。单机存档只允许存活时保存，因此报告不写入检查点。

验证：`tests/death_recap_rules.gd` 覆盖致命/非致命、生命护甲、武器/环境/自伤/断线来源、观战、暂停与回合清理；`tools/test_death_recap_network.py` 使用专服和两个真实客户端，确认受害者收到报告、另一客户端未收到私人报告。
