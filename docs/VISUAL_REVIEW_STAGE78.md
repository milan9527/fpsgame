# Stage78：卡宾枪曲面弹匣与固定机位复核

本轮延续stage77的材质标记诊断：换弹半程掌心附近的尖角深色块来自Magazine。本轮重建该部件，整体目标仍为continue。

## 实施

- `tools/build_assets.py` 将旧挤出轮廓改为21截面、每圈40点的弯曲圆角壳体，修正表面朝向，增加六条随壳体弯曲的筋条、圆角底板和锁片。
- 使用石墨色注塑材料及细颗粒粗糙度，保留Magazine节点以兼容运行时弹匣抽取和接触逻辑。重新生成 `art/carbine.blend`、`client/assets/carbine.glb` 和本地PCK。
- 本轮没有重做手套或手臂；它们保留stage77状态。

## 实际截图结论

`artifacts/realism78-validation/packaged-forward/` 保存腰射、ADS、换弹1/4、1/2、3/4五张1280×800截图。相机、武器和捕获脚本与stage77一致。包内Forward+使用llvmpipe软件Vulkan，捕获PASS且进程退出0。

已查看 `comparison-all-poses.jpg`、`comparison-hand-crop.png` 及腰射、ADS、半程原图：

- 腰射中弹匣轮廓更圆润，侧面筋条可见；正常视距的整体差异有限。
- 半程裁切中，掌心旁原先突出的尖角暗面减弱，轮廓更贴合手部。但弹匣仍被手掌遮挡较多，不能据此认定握持姿态或穿插已全面解决。
- ADS画面保持中心瞄具构图，未看到本次修改造成的明显新增遮挡。
- 掌面依然偏平，腕部连接和织物纹理仍不够自然；换弹时枪托底板大幅朝向镜头，影响武器结构辨识。仓库重复、草丛排列和远景树带仍明显，光照层次不足。人物和环境本轮未改善。

## 验证及范围

`test-results.json`：源码与独立包各8项、共16项退出0并有PASS标记：手套表面规则、瞄准、换弹接触、枪口遮挡、viewmodel规则、武器显示规则、入口雨棚碰撞、单机冒烟。

每种运行方式包含108个瞄准样本、三武器183个换弹接触样本、32个雨棚96次底面射线。单机冒烟覆盖16演员及换弹、治疗、伤害、胜利等。入口测试仅代表雨棚射线，不能替代全场人工移动碰撞检查；remote_snapshot规则也不等于真实联网。

Blender构建和PCK导出退出0；导入仍记录 `Parameter "t" is null`，没有宣称导入无错误。真实认证联网、实体GPU性能和完整人工游戏验证未执行；本轮未读取认证密钥或修改后台服务。

预览：`./artifacts/realism78-preview/Linux/IronMeridian --path /tmp`。同目录有PCK、README、build.json哈希和verification.json。
