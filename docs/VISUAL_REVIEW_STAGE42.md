# Stage42：支撑手包握形体与换弹朝向

本轮为局部开发阶段，整体目标仍为 **continue**。保留此前未提交修改，未推送、发布或改动后台服务。

## 改动

- `tools/build_viewmodel.py` 重建左手四指：沿护木长度排列，横向从下方绕至另一侧；增加上翻的对握拇指、鱼际连接、指节皮革与折缝。右手沿用原形体，重新生成 Blender/GLB。
- `client/scripts/first_person.gd` 移除换弹时旧握拳使用的额外九十度旋转，使新横向手指绕向弹匣。保留按弹匣边界定位掌心和伸手/收手权重。
- 第一版换弹截图出现手指在弹匣旁竖起的问题，虽然掌心接触规则通过，视觉不合格；修正朝向后重新截图。失败图保存在 `artifacts/realism42-validation/before-reload-orientation/`，修正对照在 `artifacts/realism42-comparison/reload-orientation-fix.png`。掌心测试不能替代指尖视觉审阅。

## 实机画面与局限

使用 Godot 4.4.1 Forward+、Xvfb、llvmpipe 软件 Vulkan，原图为 1280×800。固定角色位置、偏航和俯仰，腰射与 ADS 使用各自正常 FOV；与 stage41 的相应姿态对照。武器0来自当前源项目，武器1/2来自最终 PCK。

完成并审阅三把武器各5张，共15张截图（腰射、ADS、换弹三个时点）。原图：`artifacts/realism42-preview/capture/`；对照：`artifacts/realism42-comparison/`。

腰射中拇指上翻、指节从下方托住护木的轮廓更合理，但屏幕占比小，全景改善有限。ADS 中手部大多被机匣遮住，中心视线未新增手指遮挡。换弹朝向修正减轻了张开手爪的观感。手套仍偏圆管/块面，袖口连接偏紧，三种护木仍共用同一手形；未实现逐指骨骼、逐武器精确接触或手指物理碰撞。九格换弹对照中，SR 中点拇指与弹匣仍有可见间隙，AR/SG 指尖大部分被遮住，因此不能宣称三种武器已实现准确包握。

枪体大平面仍光滑，人物并未在本轮改善。重复草丛、方盒建筑、光滑山坡和远树剪影仍明显，离接近和平精英的整体表现仍有距离。
