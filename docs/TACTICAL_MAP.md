# 战术地图与个人路标

存活且对局进行中按 M 打开地图。M、Esc 或返回按钮关闭；B 可切换到背包。地图与背包不能同时展开，打开暂停菜单时会收起地图。

地图显示 240×240 米地形范围、16 座建筑轮廓、道路、散布掩体、40 米网格、当前安全区、剩余时间和自己的朝向。北方对应世界 -Z。道路和建筑数据由实际场景生成函数记录，不使用另一份手绘坐标。地图不显示敌人、补给位置或未来安全区。

左键设置个人路标，右键清除。路标限制在角色实际移动边界 ±115 米内。HUD 显示水平距离，小地图显示路标；小地图范围以外的路标被限制在其边缘，展开地图可看准确位置。虚线表示直线方位，不是绕开建筑的可通行路线，也不会自动移动角色。

地图不会暂停单机或在线对局。打开时移动、射击和视角输入被隔离，其他角色、缩圈和计时继续运行。关闭后仍按住的鼠标不会立刻开火；需松开再按。路标只保存在本地，死亡、对局结束、返回菜单和新回合时清除。当前没有队伍共享标记、地图缩放或路线自动规划。

`tests/tactical_map_rules.gd` 验证场景轮廓、双向坐标转换、标记边界、距离、按键与鼠标隔离、菜单互斥、安全区更新和清理。`tools/test_map_network.py` 使用图形窗口真实客户端，验证地图打开时权威对局仍推进，角色不会移动或开火，位置与安全区跟随服务器快照。
