下载后开始游戏

  1. Windows：右键 ZIP 选择“全部解压”，打开文件夹，双击 IronMeridian.exe。无需安装 Godot 或运行脚本。
  2. Linux：解压安装包，在游戏目录执行 ./play.sh --max-fps 60。
  3. 单机直接选择离线模式，无需账号。
  4. 联网时在游戏内创建账号或登录。Windows 新客户端已预填以下服务器地址；Linux 客户端请填写：
正在获取服务器地址…

账号操作全部在安装后的游戏内完成，本网站不收集用户名或密码。联网无需 SSH 转发。
