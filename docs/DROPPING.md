# 主动丢弃物资

按 B 打开背包，在右下方选择弹药、医疗包或手雷，输入数量后点击 DROP。弹药仅从共享储备扣除，不卸下三枪弹匣；护甲与枪械目前不能主动丢弃。

服务器按当前角色位置放置物资，不接受客户端提供位置。丢弃物资可由自己或其他参战者按 E 或从背包拾取，原有容量、距离、遮挡与部分取用规则继续生效。在 0.25 米内且无遮挡的同类掉落堆会合并，避免原地反复丢弃生成大量实体。

协议 7 的可靠请求携带回合 ID、操作序号、类别和整数数量。服务器与其他可靠操作共用序号去重及每秒 10 次的预算；拒绝旧回合、死亡、非进行中、积压请求、非法类型、非正数量、超过 300 或超过当前库存的数量。已被限流消费的序号不能稍后重放。医疗包在治疗完成时扣除，因此治疗中禁止丢弃医疗包。

`tests/drop_rules.gd` 覆盖按钮、库存守恒、原地合并、其他角色部分拾取、重放、边界、治疗、限流、积压、回合与死亡。`tools/test_drop_network.py` 用图形窗口真实客户端验证丢弃、服务端数量同步、重放拒绝和再次拾取。
